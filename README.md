# OpaWare

Mad toyshop gift catalog for grandparents and grandkids — workshop warmth, wry humor, handmade curiosity.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173

## Build

```bash
npm run build
npm run preview
```

Demo only — mock cart/checkout, no real payments. Custom domain `opaware.com` is aspirational / user-owned separately from Cursor hosting.
